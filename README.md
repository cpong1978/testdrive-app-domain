# testDrive app domain

Public application information, privacy policy and terms for the testDrive Google OAuth application. Built as static HTML/CSS for GitHub Pages, without dependencies, analytics, client-side JavaScript or a backend.

## Pages

- `index.html`: application overview
- `privacy.html`: privacy policy
- `terms.html`: terms of use

App operator and support: cpong1978, cpong1978@gmail.com.

The website does not host Drive files or OAuth credentials. Keep all application configuration, tokens, caches, logs and credentials outside this repository.

## Hosting

Publish from the `main` branch and repository root using GitHub Pages. `.nojekyll` serves these files directly. Relative links support a GitHub Pages project URL.

Review the policies whenever the application behavior changes. A multi-user file gateway is not part of the current setup; update the disclosures before launching it. Website publication does not itself publish or verify the Google OAuth application.
