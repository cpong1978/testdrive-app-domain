Your Drive.

testDrive is a personally operated desktop setup that uses Rclone to access an authorized Google Drive account from Windows.

WHAT IT DOES

Cloud files, accessed locally.

After the account owner grants permission through Google, Rclone mounts the account as a drive on the operator's Windows computer. The operator can list folders, read and download files, and upload, update, move or delete files within the granted permissions.

Google Drive remains the cloud storage provider. Local caching helps the desktop access files, and changes can upload in the background.

01 / AUTHORIZE

The account owner stays in control.

Google handles the account sign-in and consent. The desktop setup receives access tokens; this website does not ask for your Google password.

02 / ACCESS

Files are handled by the desktop setup.

The configured Drive permission allows broad access to files in the authorized account, rather than only files created by testDrive. Only grant access to an account you intend to use.

03 / REVOKE

Access can be withdrawn.

The account owner can revoke the application's Google access. Previously cached or downloaded files require separate removal from the desktop.

About this website

This public site provides application information, a privacy policy and terms of use for the testDrive OAuth application. It does not offer public file hosting, account registration, a file browser or access to the operator's Drive.

A multi-user file-sharing gateway is not part of the current setup. These disclosures must be updated before adding that capability.
